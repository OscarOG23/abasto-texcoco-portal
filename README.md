# Abasto Texcoco · Portal de las unidades

Interfaz pública para entregar JSON/Excel, recuperar comprobantes y consultar el cruce CPM/APS.

[Entrar al portal](https://oscarog23.github.io/abasto-texcoco-portal/)

La página se comunica con el servicio público de Apps Script sin enviar cookies de cuentas Google. Los originales, la recepción y el procesamiento permanecen en Google Drive y Apps Script. Este repositorio contiene únicamente la distribución HTML; no contiene inventarios, CPM, originales, credenciales ni el código del panel regional.

El acceso regional requiere la cuenta responsable autorizada. Conocer una CLUES identifica la unidad consultada; no autentica personalmente a quien entrega.
